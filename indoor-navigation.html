Frequently Asked Questions

How does GREXON handle dynamic obstacles during navigation?

When workers or sensors flag a blocked aisle, temporary spill, or forklift congestion, GREXON dynamically recalculates edge weights across the spatial mesh using weighted A* pathfinding, routing subsequent pickers around the obstacle with zero delay.

Can GREXON run on standard Zebra and Honeywell handheld scanners?

Yes. GREXON's navigation client is optimized for lightweight web and native Android industrial terminals, providing turn-by-turn graphical navigation with minimal battery and memory overhead.
