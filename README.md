## 🚀 Getting Started

### 1. Run Live Demo (Browser)
Simply open `index.html` in any web browser:
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

### 2. Local Development Server
```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx serve .
```
Navigate to `http://localhost:8080` in your browser.
